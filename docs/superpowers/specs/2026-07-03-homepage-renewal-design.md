# ikkeum.com 홈페이지 리뉴얼 설계

날짜: 2026-07-03
상태: 사용자 리뷰 대기

## 1. 배경과 목적

주식회사 이끔은 현재 ikkeum.com에 단일 "커밍순" 페이지만 운영 중이다. ThinkCode 론칭을 계기로, 자사 제품과 용역 사업을 소개하는 정식 회사 홈페이지로 리뉴얼한다.

**목적 (우선순위순)**
1. 자사 제품 노출 및 각 제품 사이트로 트래픽 전달 (최우선)
2. 용역(일반 SI + AX 컨설팅) 소개 및 문의 유치
3. 회사 신뢰도·공신력 확보 (지원사업 심사, 계약 상대방, 검색 유입 대응)

**포지셔닝**: 모던 기술기반 스타트업 — 키워드 AX · AI · Data · S/W

## 3. 페이지 구조

```
헤더(sticky)   로고 · 앵커 내비(제품/서비스/회사/문의) · KO/EN · (라이트 토글)
① Hero        헤드라인 + 서브카피 + AX·AI·Data·S/W 키워드 pill
              CTA: [제품 보기 ↓] [프로젝트 문의 →]
② Products    제품 카드 4장 (주인공 섹션)
③ Services    용역 2트랙: SI(시스템 구축·운영) / AX 컨설팅
              + 실적 스트립(수치·고객명) — 용역 신뢰 근거
④ About       미션 + 회사 팩트 라인
⑤ Contact     이메일·전화 대형 배치
푸터           법적 정보(기존 커밍순 페이지에서 이관: 대표자·사업자번호·주소·대표번호)
```

### ③ Services 상세

- **SI — 시스템 구축·운영**: 공공·민간 시스템 기획→설계→개발→운영 일괄 수행. 근거: 질병관리청 하수기반 감염병 통합관리 플랫폼, NHN KCP 관리자 시스템 등 납품 경험 (팀 기준 서술)
- **AX 컨설팅**: AI 도입 전략, LLM 활용 설계, 데이터 파이프라인 구축 등 AI 전환 컨설팅. 근거: 자체 AI SaaS(PlanAuto 등)를 직접 만들어 운영하는 팀
- **실적 스트립**: "누적 프로젝트 20+ · 팀 경험 6년+ · 운영 서비스 4종 · 공공/민간 납품 검증" 식 수치 나열. 문구는 신설 법인임을 감안해 "구성원/팀 누적 기준"으로 오해 없게 작성

## 4. 디자인 방향

- 딥 다크 배경(#0A0C10대) + 포인트 컬러 1개(일렉트릭 블루 계열), 절제된 글로우·그리드 패턴
- Pretendard 유지(jsdelivr CDN), 큰 헤드라인·넉넉한 여백 계승
- 다크 기본 + 라이트 모드 토글 유지 (기존 localStorage 패턴 재활용)
- 기존 reveal 애니메이션·prefers-reduced-motion 대응 패턴 재활용
- 카드·버튼 등 인터랙션은 hover 시 미묘한 상승/보더 강조 수준으로 절제

## 5. 유지·이관·수정 사항

**유지 (기존 index.html에서 재활용)**
- KO/EN 토글 로직, 테마 토글 로직, 테마 사전 초기화 스크립트(FOUC 방지)
- SEO 인프라: canonical, hreflang, OG/Twitter 카드, robots.txt
- 푸터 법적 정보 블록

**갱신**
- title/description/OG 문구: "곧 만나요/오픈 예정" → 실제 회사 소개로 전면 교체
- JSON-LD: Organization 유지 + 제품 4종을 `SoftwareApplication`(또는 `Organization.owns`)으로 추가
- sitemap.xml lastmod 갱신

**이전 분석에서 발견된 수정사항 함께 반영**
- `nav.topbar__meta`의 `aria-hidden` 시맨틱 모순 해소
- 초기 `theme-color` 메타를 다크 배경색과 통일
- 로고: 가능하면 SVG 자산 활용 (다크 테마 기본이므로 색상 변형 확인)

## 6. 하지 않는 것 (YAGNI)

- 문의 폼, 백엔드, 뉴스레터
- 블로그/뉴스 섹션
- 멀티페이지, 빌드 도구, 프레임워크 도입
- 아이디얼 브랜드 표기 및 개인사업자 이력 서술

## 7. 검증 방법

1. 로컬: `python3 -m http.server`로 서빙 → KO/EN 토글, 테마 토글, 앵커 내비, 모바일(375px)/데스크톱 뷰 확인
2. 링크: think-code.ai, planauto.kr 외부 링크 target/rel 확인
3. 접근성: reduced-motion, focus-visible, 색 대비(다크 배경 기준 AA) 확인
4. 배포 후: https://ikkeum.com 라이브 확인 (Pages 캐시 max-age=600), OG 카드 미리보기(카카오톡 디버거) 확인
